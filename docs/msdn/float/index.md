# Float methods

Methods on a `float` value, called with a dot: `value.toString(...)`

| Method | Description |
| --- | --- |
| [`abs`](abs.md) | The absolute value. |
| [`clamp`](clamp.md) | Constrains the value to a range. |
| [`round`](round.md) | Rounds to the nearest integer, or to n digits. |
| [`toInt`](toInt.md) | Truncates toward zero. |
| [`toString`](toString.md) | The decimal representation. |
