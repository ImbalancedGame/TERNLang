# d3d12.available

True when the Direct3D 12 library could be loaded.

## Syntax

```tern
d3d12.available()
```

## Parameters

_None._

## Return value

- Type: `bool`
- Whether a device can be asked for.

## Example

```tern
println(d3d12.available());
```
