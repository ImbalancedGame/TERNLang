# list.isEmpty

True when the list has no items.

## Syntax

```tern
list.isEmpty()
```

`receiver` is the list on the left of the dot.

## Return value

- Type: `bool`
- Whether the length is zero.

## Example

```tern
println([].isEmpty());
```
