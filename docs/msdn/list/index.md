# List methods

Methods on a `list` value, called with a dot: `value.push(...)`

| Method | Description |
| --- | --- |
| [`all`](all.md) | True when the callback accepts every item. |
| [`any`](any.md) | True when the callback accepts at least one item. |
| [`clear`](clear.md) | Removes every item in place. |
| [`clone`](clone.md) | A shallow copy. |
| [`concat`](concat.md) | A new list with another appended. |
| [`contains`](contains.md) | True when a value is present. |
| [`drop`](drop.md) | A copy without the first n items. |
| [`each`](each.md) | Calls a callback for each item. |
| [`filter`](filter.md) | A new list of the items the callback accepts. |
| [`find`](find.md) | The first item the callback accepts. |
| [`findIndex`](findIndex.md) | The index of the first item the callback accepts. |
| [`first`](first.md) | The first item. |
| [`flatten`](flatten.md) | Flattens nested lists. |
| [`indexOf`](indexOf.md) | The index of the first occurrence. |
| [`insert`](insert.md) | Inserts an item at an index. |
| [`isEmpty`](isEmpty.md) | True when the list has no items. |
| [`join`](join.md) | Joins the items into a string. |
| [`last`](last.md) | The last item. |
| [`map`](map.md) | A new list of callback results. |
| [`max`](max.md) | The largest item. |
| [`min`](min.md) | The smallest item. |
| [`pop`](pop.md) | Removes and returns the last item. |
| [`push`](push.md) | Appends values in place. |
| [`reduce`](reduce.md) | Folds the list into one value. |
| [`remove`](remove.md) | Removes and returns the item at an index. |
| [`removeValue`](removeValue.md) | Removes the first occurrence of a value. |
| [`reverse`](reverse.md) | Reverses in place. |
| [`shift`](shift.md) | Removes and returns the first item. |
| [`slice`](slice.md) | A copy of a half-open index range. |
| [`sort`](sort.md) | Sorts in place. |
| [`sum`](sum.md) | The sum of the numeric items. |
| [`take`](take.md) | A copy of the first n items. |
| [`toString`](toString.md) | A debug rendering of the list. |
| [`unique`](unique.md) | A new list without duplicates. |
| [`unshift`](unshift.md) | Prepends values in place. |
