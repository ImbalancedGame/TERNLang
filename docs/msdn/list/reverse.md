# list.reverse

Reverses in place.

## Syntax

```tern
list.reverse()
```

`receiver` is the list on the left of the dot.

## Return value

`nil`.

## Example

```tern
let xs = [1, 2, 3];
xs.reverse();
println(xs);
```
