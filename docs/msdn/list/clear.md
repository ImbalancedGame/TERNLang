# list.clear

Removes every item in place.

## Syntax

```tern
list.clear()
```

`receiver` is the list on the left of the dot.

## Return value

`nil`.

## Example

```tern
let xs = [1, 2];
xs.clear();
println(xs.isEmpty());
```
