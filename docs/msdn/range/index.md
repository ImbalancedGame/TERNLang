# Range methods

Methods on a `range` value, called with a dot: `value.toList(...)`

| Method | Description |
| --- | --- |
| [`contains`](contains.md) | True when a number is inside the range. |
| [`each`](each.md) | Calls a callback for each value. |
| [`length`](length.md) | How many values the range yields. |
| [`map`](map.md) | A list of callback results over the range. |
| [`toList`](toList.md) | Materialises the range as a list. |
| [`toString`](toString.md) | The range in its source notation. |
