# println

Writes its arguments and a newline.

## Syntax

```tern
println(values...)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `values` | `any` | Any number, including none. |

## Return value

`nil`.

## Example

```tern
println("hello", "world");
```
