# fs.isDir

True for a directory.

## Syntax

```tern
fs.isDir(path)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `path` | `string` | The path. |

## Return value

- Type: `bool`
- Whether it is a directory.

## Example

```tern
println(fs.isDir("docs"));
```
