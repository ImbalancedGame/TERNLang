# map.keys

The keys, in insertion order.

## Syntax

```tern
map.keys()
```

`receiver` is the map on the left of the dot.

## Return value

- Type: `list`
- The keys.

## Example

```tern
println({"b": 1, "a": 2}.keys());
```
