# Map methods

Methods on a `map` value, called with a dot: `value.keys(...)`

| Method | Description |
| --- | --- |
| [`clear`](clear.md) | Removes every key in place. |
| [`clone`](clone.md) | A shallow copy. |
| [`contains`](contains.md) | True when the key exists; an alias of `has`. |
| [`entries`](entries.md) | Key and value pairs. |
| [`get`](get.md) | The value for a key, or a default. |
| [`has`](has.md) | True when the key exists. |
| [`isEmpty`](isEmpty.md) | True when the map has no keys. |
| [`keys`](keys.md) | The keys, in insertion order. |
| [`merge`](merge.md) | A new map with another map's pairs merged in. |
| [`remove`](remove.md) | Deletes a key. |
| [`set`](set.md) | Inserts or replaces a key. |
| [`toString`](toString.md) | A debug rendering of the map. |
| [`values`](values.md) | The values, in insertion order. |
