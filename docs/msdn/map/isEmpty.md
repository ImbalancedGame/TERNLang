# map.isEmpty

True when the map has no keys.

## Syntax

```tern
map.isEmpty()
```

`receiver` is the map on the left of the dot.

## Return value

- Type: `bool`
- Whether the size is zero.

## Example

```tern
println({}.isEmpty());
```
