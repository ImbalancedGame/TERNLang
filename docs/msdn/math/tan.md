# math.tan

The tangent of an angle in radians.

## Syntax

```tern
math.tan(angle)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `angle` | `number` | Radians. |

## Return value

- Type: `float`
- The tangent.

## Example

```tern
println(math.round(math.tan(math.pi / 4)));
```
