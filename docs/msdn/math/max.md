# math.max

The largest argument.

## Syntax

```tern
math.max(values...)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `values` | `number` | One or more numbers. |

## Return value

- Type: `number`
- The largest.

## Example

```tern
println(math.max(3.0, 1.0, 2.0));
```
