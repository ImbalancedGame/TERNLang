# math.log2

The base 2 logarithm.

## Syntax

```tern
math.log2(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | A positive number. |

## Return value

- Type: `float`
- The logarithm.

## Example

```tern
println(math.log2(1024.0));
```
