# math.exp

Raises e to a power.

## Syntax

```tern
math.exp(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | The exponent. |

## Return value

- Type: `float`
- e to the power.

## Example

```tern
println(math.exp(0.0));
```
