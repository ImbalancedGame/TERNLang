# math.cos

The cosine of an angle in radians.

## Syntax

```tern
math.cos(angle)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `angle` | `number` | Radians. |

## Return value

- Type: `float`
- The cosine.

## Example

```tern
println(math.round(math.cos(0.0)));
```
