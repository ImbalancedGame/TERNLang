# math.cbrt

The cube root.

## Syntax

```tern
math.cbrt(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | Any number. |

## Return value

- Type: `float`
- The root, negative for a negative argument.

## Example

```tern
println(math.cbrt(-27.0));
```
