# math.toRadians

Degrees to radians.

## Syntax

```tern
math.toRadians(degrees)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `degrees` | `number` | The angle in degrees. |

## Return value

- Type: `float`
- The angle in radians.

## Example

```tern
println(math.toRadians(180.0) == math.pi);
```
