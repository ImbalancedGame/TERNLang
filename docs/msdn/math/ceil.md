# math.ceil

Rounds up to an integer.

## Syntax

```tern
math.ceil(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | The value. |

## Return value

- Type: `float`
- The smallest whole number not less than the value, as a float: `2.0`.

## Example

```tern
println(math.ceil(1.2));
```
