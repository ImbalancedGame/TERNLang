# math.infinity

Positive infinity.

## Syntax

```tern
math.infinity()
```

## Parameters

_None._

## Return value

- Type: `float`
- Infinity; its negative is `-math.infinity`.

## Example

```tern
println(math.infinity > 1e308);
```
