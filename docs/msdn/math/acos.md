# math.acos

The arc cosine.

## Syntax

```tern
math.acos(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | -1..1. |

## Return value

- Type: `float`
- The angle in radians.

## Example

```tern
println(math.acos(1.0));
```
