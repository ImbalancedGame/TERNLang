# math.sin

The sine of an angle in radians.

## Syntax

```tern
math.sin(angle)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `angle` | `number` | Radians. |

## Return value

- Type: `float`
- The sine.

## Example

```tern
println(math.sin(math.pi / 2));
```
