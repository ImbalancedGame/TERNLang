# math.asin

The arc sine.

## Syntax

```tern
math.asin(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | -1..1. |

## Return value

- Type: `float`
- The angle in radians; NaN outside the domain.

## Example

```tern
println(math.asin(1.0));
```
