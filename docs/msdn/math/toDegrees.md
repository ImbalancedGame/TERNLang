# math.toDegrees

Radians to degrees.

## Syntax

```tern
math.toDegrees(radians)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `radians` | `number` | The angle in radians. |

## Return value

- Type: `float`
- The angle in degrees.

## Example

```tern
println(math.toDegrees(math.pi));
```
