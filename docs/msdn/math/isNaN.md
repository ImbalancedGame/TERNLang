# math.isNaN

True for NaN.

## Syntax

```tern
math.isNaN(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `any` | The value. |

## Return value

- Type: `bool`
- Whether it is a float that is not a number.

## Example

```tern
println(math.isNaN(math.nan));
```
