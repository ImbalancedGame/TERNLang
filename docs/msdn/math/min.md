# math.min

The smallest argument.

## Syntax

```tern
math.min(values...)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `values` | `number` | One or more numbers. |

## Return value

- Type: `number`
- The smallest.

## Example

```tern
println(math.min(3.0, 1.0, 2.0));
```
