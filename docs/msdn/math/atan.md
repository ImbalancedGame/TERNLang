# math.atan

The arc tangent.

## Syntax

```tern
math.atan(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | Any number. |

## Return value

- Type: `float`
- The angle in radians, in -pi/2..pi/2.

## Example

```tern
println(math.atan(1.0));
```
