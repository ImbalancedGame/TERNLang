# math.abs

The absolute value.

## Syntax

```tern
math.abs(value)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | `number` | The value. |

## Return value

- Type: `number`
- Its magnitude, of the same kind.

## Example

```tern
println(math.abs(-2.5));
```
