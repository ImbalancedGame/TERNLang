# string.upper

An uppercased copy.

## Syntax

```tern
string.upper()
```

`receiver` is the string on the left of the dot.

## Return value

- Type: `string`
- The copy; the receiver is unchanged, since strings are immutable.

## Example

```tern
println("aBc".upper());
```
