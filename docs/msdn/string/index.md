# String methods

Methods on a `string` value, called with a dot: `value.upper(...)`

| Method | Description |
| --- | --- |
| [`chars`](chars.md) | The string as single-character strings. |
| [`contains`](contains.md) | True when the substring occurs. |
| [`count`](count.md) | Counts non-overlapping occurrences of a substring. |
| [`endsWith`](endsWith.md) | True when the string ends with the suffix. |
| [`format`](format.md) | Formats the string as a template. |
| [`indexOf`](indexOf.md) | The index of the first occurrence. |
| [`isEmpty`](isEmpty.md) | True when the string has no characters. |
| [`lastIndexOf`](lastIndexOf.md) | The index of the last occurrence. |
| [`lines`](lines.md) | The non-empty lines of a text. |
| [`lower`](lower.md) | A lowercased copy. |
| [`padEnd`](padEnd.md) | Right-pads to a width. |
| [`padStart`](padStart.md) | Left-pads to a width. |
| [`repeat`](repeat.md) | The string repeated n times. |
| [`replace`](replace.md) | Replaces every occurrence of a substring. |
| [`replaceFirst`](replaceFirst.md) | Replaces the first occurrence of a substring. |
| [`reversed`](reversed.md) | The string backwards. |
| [`slice`](slice.md) | A substring from start to end. |
| [`split`](split.md) | Splits the string on a separator. |
| [`startsWith`](startsWith.md) | True when the string begins with the prefix. |
| [`substring`](substring.md) | A substring between two indices. |
| [`toFloat`](toFloat.md) | Parses the string as a float. |
| [`toInt`](toInt.md) | Parses the string as an integer. |
| [`toString`](toString.md) | The string itself. |
| [`trim`](trim.md) | The string without leading and trailing whitespace. |
| [`trimEnd`](trimEnd.md) | The string without trailing whitespace. |
| [`trimStart`](trimStart.md) | The string without leading whitespace. |
| [`upper`](upper.md) | An uppercased copy. |
| [`words`](words.md) | Splits on runs of whitespace. |
