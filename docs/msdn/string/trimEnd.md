# string.trimEnd

The string without trailing whitespace.

## Syntax

```tern
string.trimEnd()
```

`receiver` is the string on the left of the dot.

## Return value

- Type: `string`
- The copy.

## Example

```tern
println("a  ".trimEnd() + "|");
```
