# string.isEmpty

True when the string has no characters.

## Syntax

```tern
string.isEmpty()
```

`receiver` is the string on the left of the dot.

## Return value

- Type: `bool`
- Whether the length is zero.

## Example

```tern
println("".isEmpty(), " ".isEmpty());
```
