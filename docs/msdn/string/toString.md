# string.toString

The string itself.

## Syntax

```tern
string.toString()
```

`receiver` is the string on the left of the dot.

## Return value

- Type: `string`
- The receiver.

## Remarks

Present so that any value can be stringified the same way.

## Example

```tern
println("a".toString());
```
