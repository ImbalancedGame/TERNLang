# string.trimStart

The string without leading whitespace.

## Syntax

```tern
string.trimStart()
```

`receiver` is the string on the left of the dot.

## Return value

- Type: `string`
- The copy.

## Example

```tern
println("  a".trimStart() + "|");
```
