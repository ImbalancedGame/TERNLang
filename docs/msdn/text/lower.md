# text.lower

A lowercased copy.

## Syntax

```tern
text.lower(text)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `text` | `string` | The text. |

## Return value

- Type: `string`
- The copy.

## Example

```tern
println(text.lower("ABC"));
```
