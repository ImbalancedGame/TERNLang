# text.upper

An uppercased copy.

## Syntax

```tern
text.upper(text)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `text` | `string` | The text. |

## Return value

- Type: `string`
- The copy.

## Example

```tern
println(text.upper("abc"));
```
