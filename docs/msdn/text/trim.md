# text.trim

Text without surrounding whitespace.

## Syntax

```tern
text.trim(text)
```

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `text` | `string` | The text. |

## Return value

- Type: `string`
- The trimmed copy.

## Example

```tern
println(text.trim("  a  ") + "|");
```
