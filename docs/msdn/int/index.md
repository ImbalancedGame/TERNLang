# Integer methods

Methods on a `int` value, called with a dot: `value.toString(...)`

| Method | Description |
| --- | --- |
| [`abs`](abs.md) | The absolute value. |
| [`clamp`](clamp.md) | Constrains the value to a range. |
| [`times`](times.md) | Calls a callback n times. |
| [`toFloat`](toFloat.md) | The same value as a float. |
| [`toString`](toString.md) | The decimal representation. |
